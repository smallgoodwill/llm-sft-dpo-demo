## 记录规范

1. 每次评测记录 commit、`--seed`、`BASE_MODEL` 路径，便于回溯。
2. 指标保留 3 位小数（脚本输出即为 0.xxx）。
3. 主观抽样：每类抽 2 条贴到 PR 描述里，避免「指标涨了但话术变差」。
